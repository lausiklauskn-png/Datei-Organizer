# Datei-Organizer

Alles in einen Ordner legen – der Organizer sortiert Klick für Klick feiner: Art, Briefkopf, Kategorie und Nummern, Absender,
Inhalt. Am Ende ist jede Datei unter vielen Gesichtspunkten zu finden und geht vorsortiert in die Familienakte.
